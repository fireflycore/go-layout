## 代码迁移点（registry etcd）

### 1) 服务注册实现包路径迁移

文件：[register.go](file:///d:/project/firefly/go-layout/internal/server/register.go)

旧实现：

- import github.com/fireflycore/go-micro/registry/etcd
- etcd.NewRegister(...)

新实现：

- import github.com/fireflycore/go-etcd/registry
- registry.NewRegister(...)

注意：

- go-etcd/registry 提供的是“etcd 注册中心实现”，接口类型仍复用 go-micro/registry 中的 Register、Meta、ServiceConf 等。
- 同一个文件里同时需要使用 go-micro/registry（接口与类型）与 go-etcd/registry（实现），建议统一采用以下 import 方式，避免各服务 AI 升级时别名不一致：

  - github.com/fireflycore/go-micro/registry（保持包名 registry）
  - etcd "github.com/fireflycore/go-etcd/registry"（实现包统一别名为 etcd，不使用 etcdRegistry）

  参考：

  - etcd.NewRegister(cli, &meta, conf)
