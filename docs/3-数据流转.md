# 数据流转

```markdown
[ 外部请求 (gRPC/HTTP) ]
     ↓
[ DTO ] (dep/protobuf/ 生成)
     ↓ (service/convert/ 转换 + protovalidate 验证)
[ Service 层 ] (参数验证、权限检查、事务控制)
     ↓
[ DO ] (internal/biz/model/) ← 业务逻辑 (UseCase 层)
     ↓ (通过 Repository 接口)
[ DAO ] (internal/data/)
     ↓ (biz/model)
[ PO ] (internal/data/entity/)
     ↓ (ORM 操作)
[ 数据库 (MySQL/PostgreSQL) ]

响应流程：
[ 数据库 ] → [ PO ] → [ DO ] → [ DTO ] → [ 客户端响应 ]
```
